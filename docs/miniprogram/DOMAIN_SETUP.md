## Windows 接入执行顺序

1. 在目标 Windows 执行 `ipconfig`，确认实际联网网卡的 IPv4 与默认网关。不要把 `192.168.*`、`10.*`、`172.16–31.*` 等内网地址填入公网 A 记录。
2. 在路由器管理页面查看 WAN / 上网 IP；对照运营商实际分配地址，判断是否存在上级 NAT。若为运营商 NAT，单纯端口映射不能提供公网入口，需要运营商公网接入或另选有公网入口的隧道服务。尚未选择、开通或购买隧道服务。
3. 获取 Windows 远程管理访问能力，检查运行依赖并部署项目。正式 API 只监听回环地址，关闭开发登录；AppSecret 仅在目标电脑服务器环境中配置，不发送到聊天中。
4. 根据实际接入方式配置入口：直连时将公网 80 / 443 转发到 HTTPS 代理，不将 8010 或桌面管理服务暴露到公网；隧道时按选定服务要求设置 CNAME。不要同时设置冲突记录。
5. 设置 DNS：主机记录 `api`；直连使用 A / 可用时 AAAA，值为真实公网入口地址。值尚未取得，不可预填。配置证书前验证解析与入口连通性。
6. 接入条件满足后可使用自动签发 / 续期工具配置 HTTPS；Caddy 的 HTTP / TLS 验证需要外网验证请求可到达对应端口，DNS 验证需要另外配置 DNS 提供商权限。当前未安装或启用证书服务。
7. 从外网运行 `python scripts/check_miniprogram_public.py`，验证证书及正式健康检查；再切换客户端生产配置、配置微信服务器域名、进行真机联调。本脚本只验收 HTTPS 健康检查，不代表完成微信备案或端到端验收。

本轮已获得用户接入与联调授权；实际执行仍依赖目标电脑连接及公网入口。当前未修改 DNS、路由器、Windows 防火墙或线上配置。
