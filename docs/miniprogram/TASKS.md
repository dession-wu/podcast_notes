## F. 需用户操作或确认的节点
1. **注册与备案**：用户实名注册，提供非敏感 AppID；AppSecret 只在服务器安全配置，不发到聊天或前端。
2. **购买资源**：先展示供应商、地区、规格、价格、用途，再确认购买；本阶段不购买。
3. **付费转写/API**：先核对价格与费用上限，再启用；本阶段不调用付费接口。
4. **内容与隐私定稿**：用户确认实际授权、运营主体、存储期限、处理服务商、联系方式；草稿不可直接用于上线。
5. **上线**：先交付体验版与测试结果，确认后再提交审核/正式发布。

完成标准：本地开发交付与正式上线分开记录。没有 AppID、服务器、备案、授权材料时，不声称上线完成。微信客户端无法验证时，明确记录待真机验收。
