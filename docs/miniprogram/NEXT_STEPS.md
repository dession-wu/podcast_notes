# 域名审核期间实施计划

## 本轮执行范围

用户授权继续推进上线准备，并从功能、视觉两方面优化交互。域名注册审核中，正式AppID已写入，工具—办公类目用户确认已添加。浏览器操作受区域限制，本轮通过本地文件、官方微信编译器及可用的开发者工具验证，不操作购买或正式发布。

| 顺序 | 工作 | 验收标准 |
| --- | --- | --- |
| 1 | 四页交互优化 | 搜索有最近记录与清空入口；单集按分钟显示并可筛选已加载内容；任务可按状态筛选；阅读有字号和筛选结果计数 |
| 2 | 视觉整理 | 复用青绿主色，缩小营销式标题，统一白色列表、留白、边框、按钮、状态色与底部安全区 |
| 3 | 回归验证 | 客户端行为测试、官方模板编译；模拟器可用时保留新版截图并目视检查 |
| 4 | 生产配置检查 | 提供只读发布预检，明确阻止开发登录、本机HTTP、测试号和错误正式AppID；不自动写入或泄露密钥 |
| 5 | 部署交接 | 更新当前进度和上线验收顺序，列出还需用户提供的域名、实际托管方式、内容授权及隐私联系信息 |

## 本轮设计与功能约束

- 沿用现有原生WXML/WXSS和配色，不引入Web框架或装饰性插图。主背景 `#f5f7f8`，白色内容面，青绿 `#087f72` 主操作，深色正文。
- 搜索页保留“让声音，成为文字。”，最近搜索只存本机、最多6条、不主动搜索，清空不影响服务器记录。
- 单集筛选仅覆盖已加载列表，页面明确说明范围；支持继续加载，不宣称搜索整个RSS。
- 单集时长未知时仍可提交，由服务端实际检测；已知超限提前禁用。额度、最长时长、保留天数读取服务端设置，不将旧默认写死。
- 任务状态使用真实后台阶段，不绘制估计百分比。筛选不影响轮询所有活动任务。
- 阅读字号三档，偏好仅存本机；关键词筛选仍复制/导出完整正文，并明确告知。
- 不新增收费、公开内容库、AI摘要或未经授权的第三方节目转写。

## 等域名及部署条件就绪后

本轮第1—5项已完成实现、检查与交接材料，详细证据见 [UI_VALIDATION.md](UI_VALIDATION.md)。发布预检当前按预期阻止开发配置；模板不能替代实际生产验收。以下步骤仍未完成。

1. 确认域名注册/实名状态与ICP备案状态，二者分别记录。确认公网服务实际部署地点、接入方式及备案资源。
2. 用户此前希望复用闲置电脑，但尚未确定公网入口与其分工。当前代码是单机单worker；若采用公网API加家庭转写worker，另行实施可靠任务领取、认证、租约、断线恢复和结果回传，不把反向代理模板当作已支持此架构。
3. 在目标环境实际构建镜像、预热模型、测授权长音频及小规模并发；验证数据备份和恢复。
4. 安全配置正式AppSecret，关闭开发和演示模式，配置HTTPS及微信合法域名，运行发布预检。
5. iOS/Android体验版验证登录、任务隔离、前后台切换、复制、TXT分享、长文本及异常情况。
6. 完成小程序备案、真实隐私信息与内容授权材料；认证是否办理及费用另行确认。
7. 交付体验版和测试结果后，由用户确认提交审核；通过后再确认正式发布。
